# Brand

**Colors**
- Background `#0B0D12`, panel `#12151C`, raised panel `#181C26`, hairline `rgba(255,255,255,0.10)`.
- Text `#E9EDF5`, dim `#8C96AA`, faint `#5B6478`.
- One accent: `#4F8CFF`. Green `#3DDC97` only for good/after states, red `#FF5C5C` only for bad/before states.

**Fonts** (load via `@remotion/google-fonts`)
- Inter 400–800 for UI and captions. JetBrains Mono 400–700 for code, diagram labels and the typing intro.

**Shape**
- Radius 16 px on every card, bubble and pill.
- Shadow `0 22px 60px rgba(0,0,0,.5), 0 3px 10px rgba(0,0,0,.35)`.
- Border is the 1 px hairline; an accent element gets 2 px accent.
- Safe margin 5% on all sides. Grid is 12 columns inside it.

**Captions**
- Inter 600, white, at most 2 lines, bottom center. The current word is highlighted in the accent color.
- 16:9: ~44 px. Reels: ~72–90 px, 1–3 words per line, center third of the frame.

**Icons**
- Use `simple-icons` in white or brand color on dark. For icons missing from the latest release (OpenAI, AWS S3), use the v13 alias of the same package. If an icon never existed (e.g. Inngest), use a text chip. Company names are text cards, not logos. No emojis.
