# Component index

One-page lookup for every component spec in `components/specs/` and its saved code in `components/code/` (tokens in `code/theme.ts`, Remotion version in `code/REMOTION_VERSION`). **Read this first; open a spec only when you will use it.** Never bulk-read `components/`. Pick from your scene table, open just those specs. `layout-states.md` is the HEAD / FULL / SPLIT system, not a component. "States" = layouts the spec supports; `any` = unrestricted or not stated (the spec's own rules and `brand.md` apply).
